### Hello, I'm Sushmita.

I'm an **Artificial Intelligence & Machine Learning** undergraduate at **Aditya Engineering College** with a **9.10 CGPA**, and I build software end to end: the model, the API, the database and the interface someone actually touches.

A year of full-stack training at Technical Hub taught me to carry an idea from interface to server logic to deployment. Alongside it, I shipped an LLM-powered policy analyser, a UPI & card payment gateway, and a multi-tenant SaaS platform, each one containerised and built for someone other than me to run.

Java is my primary language and Python is where my ML work lives. I care about systems that hold up: payments that settle in exactly one state, tenants that never see each other's data, and AI whose answers can be checked against the source.

### Selected work

<img src="assets/project-policyguard.svg" width="100%" alt="PolicyGuard AI: turns long, dense policy documents into answers you can check. 500+ documents processed, 92% accuracy, 60% less manual review time.">

**PolicyGuard AI** · Python, NLP, LLM, REST API<br>

<a href="https://github.com/Sushmitadasari/Payment-gateway-system-Project"><img src="assets/project-payment-gateway.svg" width="100%" alt="Payment Gateway System: UPI and card payments on a strict processing, success or failed state machine. 1,000+ transactions, 99.8% uptime, 3x throughput under load."></a>

**Payment Gateway System** · Node.js, Express, PostgreSQL, React, Docker<br>
A Razorpay-style gateway: merchants create orders through API key & secret authentication, customers pay by UPI or card on a hosted checkout with Luhn and expiry validation, and a merchant dashboard tracks every transaction. A Dockerised microservice setup cut deployment setup by 70%, and backend optimisation reduced API response time by 40%.<br>
[Repository](https://github.com/Sushmitadasari/Payment-gateway-system-Project) · [Architecture walkthrough](https://www.youtube.com/watch?v=FUOZyQT5fNI)

<a href="https://github.com/Sushmitadasari/weforshe-starcloset"><img src="assets/project-starcloset.svg" width="100%" alt="StarCloset, Myntra Bharat AI: an explainable AI fashion assistant that understands Hinglish occasions. Five-stage pipeline, ten scoring signals."></a>

**StarCloset · Myntra Bharat AI** · React 19, TypeScript, Go, PostgreSQL, Redis, optional Gemini<br>
Our team's Myntra WeForShe HackerRamp 2026 entry, which placed in the Top 100. It's a fashion assistant built on a rule-based, five-stage recommendation pipeline (Understand → Retrieve → Score → Diversify → Explain) that can explain every ranking. It understands occasions like *shaadi*, *sangeet* and *garba*, and keeps working with no LLM key configured.<br>
[Live demo](https://myntra-ai.vercel.app) · [Repository](https://github.com/Sushmitadasari/weforshe-starcloset)

<a href="https://github.com/Sushmitadasari/Multi-Tenant-SaaS-Platform"><img src="assets/project-multitenant-saas.svg" width="100%" alt="Multi-Tenant SaaS Platform: many organisations, one database, no cross-tenant access. 50+ concurrent tenants, zero unauthorised-access incidents, setup under 2 minutes."></a>

**Multi-Tenant SaaS Platform** · Node.js, React, PostgreSQL, Docker Compose<br>
A project-governance platform built on shared-database multi-tenancy. Every query is scoped by `tenant_id` through middleware, with four-level JWT/RBAC: zero unauthorised-access incidents across 200+ users. One-command Docker Compose deployment took environment setup from 45 minutes to under 2.<br>
[Repository](https://github.com/Sushmitadasari/Multi-Tenant-SaaS-Platform)
