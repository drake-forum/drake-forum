StarCloset Myntra Bharat AI

An AI fashion shopping assistant built on an explainable recommendation engine — and wrapped in a gamified luxury fashion district where each celebrity stylist’s boutique unlocks as you shop.

  • 5stage pipeline
  • 10scoring signals
  • Hinglishoccasion-aware prompt understanding
  • React 19
  • TypeScript
  • Go
  • PostgreSQL
  • Redis
  • Gemini (optional)

Product approach

  • A deliberately rule-based pipeline — Understand → Retrieve → Score → Diversify → Explain — so every ranking can be explained to a merchandiser in plain language.
  • Built for Bharat: the prompt extractor understands Hinglish occasions such as shaadi, sangeet, mehendi, haldi, garba and maps them through a cross-occasion affinity matrix.
  • Gemini is optional — with no API key every endpoint still works on the deterministic extractor.

04 SaaS · Security · 2026

Multi-Tenant SaaS Platform

A project-governance platform where many organisations share one database but never each other’s data — with subscription limits enforced at the service layer.

  • 50+concurrent tenants
  • 0unauthorised-access incidents across 200+ users
  • <2 minsetup, down from 45
  • Node.js
  • React
  • PostgreSQL
  • Docker Compose
  • JWT / RBAC

How isolation works

  • Shared-schema, row-level segregation: every query is scoped by tenant_id through middleware.
  • Four-level JWT/RBAC — auth verification, role validation, tenant filtering and subscription enforcement.
  • Kanban project and task workflow with role-sensitive assignment; one-command Docker Compose deployment.
